سازنده پروفایل DNS امن iOS

آدرس‌های DoH و DoT خود را وارد کنید تا پروفایل اختصاصی .mobileconfig با قوانین On-Demand ساخته شود.

عنوان سرویس (Service Display Name)
نوع پروتکل خروجی
آدرس سرور DoH (Server URL)
آدرس کامل HTTPS برای کوئری DoH
لطفاً آدرس معتبر DoH (شروع با https://) را وارد کنید.
نام هاست سرور DoT (Server Name / Hostname)
دامنه سرور TLS بدون پسوند و پیشوند
لطفاً نام هاست DoT را وارد کنید.
